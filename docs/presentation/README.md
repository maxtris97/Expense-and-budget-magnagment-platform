# FinFlow Project Presentation

Place your project PowerPoint (`.pptx`) or exported PDF presentation here:

- `docs/presentation/FineFlow_Presentation.pptx`
- `docs/presentation/FineFlow_Presentation.pdf` (Recommended: PDFs render automatically inside GitHub's web viewer with page-by-page slide navigation)

### How to Add Your PPT:
1. Save your PowerPoint presentation as `FineFlow_Presentation.pptx` (or `.pdf`).
2. Drag and drop it into this folder: `docs/presentation/`.
3. Commit and push to GitHub!
